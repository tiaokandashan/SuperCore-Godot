## 一、项目定位

这是 SuperCore 的 Godot 4.7.1 .NET 独立迁移项目。总根目录为 `E:\UnityProject\SuperCoreGodot`，Godot 项目位于 `Project`。整个 `E:\UnityProject\SuperCore` 是框架参考源，主框架代码入口为 `Assets/SuperCore`，可借鉴的 AI 文档为根 `AGENTS.md` 与 `ProjectDocs`。

根迁移任务为 `SCG-20260806-001`。SuperCore 启动场景、Godot Node Host、普通 C# Module 生命周期基础、`[Module(priority)]` 发现机制和 12 个 Module 启动骨架已建立；具体 Module 功能、Procedure、GameSystem 和 SuperCoreKit 尚未迁移。

## 二、固定读取

每次请求只固定读取：

1. 项目根 `AGENTS.md`。
2. 本文件。

随后按第三节条件读取，不一次性加载全部总览、手册、方案和日志。

## 六、事实与修改边界

- 当前代码、资源、配置和工作区是最高事实源。
- 当前有效文档描述当前实现；待补充文档和历史方案不能作为实现依据。
- Unity 工程整体只读参考，迁移前必须重新读取其实际源码、配置、资源、工具和调用点。
- Unity 当前代码、配置和资源高于 `ProjectDocs` 的事实优先级；AI 文档只提供定位、职责、历史取舍和验证经验。
- 已删除的旧 Godot 迁移不属于当前实现。
- 一次只迁移一个可独立验证的能力，不顺带实现后续阶段。
- 修改完成后先更新当前文档，再完成任务索引和日志。
