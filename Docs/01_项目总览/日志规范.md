# 日志规范

状态：当前有效  
适用范围：SuperCore Godot 项目修改记录  
最后更新：2026-08-06  
AI阅读优先级：高

## 一、目录和命名

日志统一存放在 `Docs/06_日志`，按月份和月内周拆分：

```text
Log(X月Y周).md
Log(X月Y周-2).md
```

基础卷无后缀，后续卷从 `-2` 连续编号。当前卷达到 80 KiB 或 1500 行后，下一任务写入下一卷；一个任务不得跨卷。

## 二、日期顺序

日志按日期倒序，日期使用一级标题；同一日期下的任务也按新到旧排列。

## 三、结构化任务

正式任务使用二级标题和 YAML：

```yaml
id: SCG-YYYYMMDD-NNN
status: draft
operation: update
created_by: "user-name"
executed_by: ["user-name"]
root_task: SCG-20260806-001
proposal: "Docs/05_任务/进行中/任务方案.md"
areas: [framework]
targets:
  files: []
  symbols: []
relation_status: linked
relations:
  continues: []
  depends_on: []
  supersedes: []
  reverts: []
  conflicts_with: []
started_at: 2026-08-06
completed_at:
```

根任务自身的 `root_task` 写 `null`。正文顺序固定为：

```text
目标 -> 结果 -> 决策 -> 约束 -> 文档 -> 后续 -> 审查 -> 验证
```

## 四、写入规则

- 创建、更新、删除、迁移和文档修改都要写日志。
- 查询和未产生修改的方案讨论不写正式任务日志。
- 写日志前检查当前周全部分卷的大小、行数和重复 ID。
- 创建任务时同步总索引、月索引和日志。
- 完成时先更新当前文档和日志，再更新索引状态。
- 文件使用 UTF-8 无 BOM。
