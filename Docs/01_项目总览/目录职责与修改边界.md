# 目录职责与修改边界

状态：当前有效  
适用范围：项目目录和修改范围判断  
最后更新：2026-08-10  
AI阅读优先级：高

## 一、项目目录

- `AGENTS.md`：AI 总入口。
- `Docs`：AI 当前文档、方案、任务索引、日志和归档。
- `Project`：唯一 Godot 4.7.1 项目根目录。
- `Project/.godot`：Godot 生成缓存，不属于框架源码。
- `Project/SuperCore`：SuperCore 框架根目录，直属目录为 `RunTime`、`Lib`、`Editor`。
- `Project/SuperCore/RunTime`：运行时框架代码和启动场景；当前一级结构为 `Assembly`、`Common`、`Log`、`Module`、`Util`。
- `Project/SuperCore/RunTime/Module`：普通 C# Module 生命周期、特性收集器和各 Module 目录；模块自有配置类型及 `.tres` 与所属 Module 放在同一目录。
- `Project/SuperCore/Lib`：框架自身库边界，当前为空。
- `Project/SuperCore/Editor`：框架 Editor 源码边界，当前为空；Godot 插件入口尚未设计。
- `Project/Tests/SuperCore`：独立生命周期测试工程；`Project/Tests/.gdignore` 阻止 Godot 导入测试源码，测试替身不能进入生产框架目录和生产配置。
- `E:\UnityProject\SuperCore`：Unity 当前框架整体参考源，只读。
- `E:\UnityProject\SuperCore\Assets\SuperCore`：主框架代码入口。
- `E:\UnityProject\SuperCore\ProjectDocs` 与根 `AGENTS.md`：可借鉴的 AI 文档源，不高于当前代码、配置和资源事实。
- `Assets/@Scripts`、`Assets/@ResourcePackage`、`Tools` 及其他配置、资源目录：由迁移子任务根据主框架实际依赖按需读取。

## 二、Docs 目录

- `00_AI快速入口.md`：固定入口和条件路由。
- `01_项目总览`：项目级规范、框架总览和领域总索引。
- `02_模块手册`：已迁移 Module 的详细当前文档。
- `03_编辑器工具`：已迁移 Godot Editor 工具的详细当前文档。
- `04_业务`：已迁移业务的详细当前文档。
- `05_任务`：待确认、进行中、已完成、暂停方案和月份索引。
- `06_日志`：周日志和正式任务详情。
- `90_历史归档`：失效或被替代资料。

## 三、当前搜索优先级

Godot 框架入口已经迁移，当前按以下顺序搜索：

1. `Project/project.godot` 和 `Project` 当前文件。
2. `Docs` 当前有效文档。
3. 根迁移任务与命中子任务。
4. Unity 工程当前源码、配置、资源、工具和调用点。
5. Unity 根 `AGENTS.md`、`ProjectDocs` 当前文档，以及命中的历史方案和日志。

具体 Module、Editor 插件、业务和 Examples 等目录职责在对应迁移任务实际建立后补充，不提前写死。

## 四、修改边界

- 只修改当前任务直接相关文件。
- 不修改 Unity 迁移源，除非用户为源工程单独给出方案和确认。
- 不恢复已删除旧迁移，不搜索备用旧路径。
- 不为一个功能新增架构层、全局入口、Module 或占位配置；`SCG-20260810-003` 已确认的启动骨架是唯一当前例外，不得据此继续扩展空实现。
- 修改公共 API 时检查全部当前调用点。
- 未明确要求时不生成正式 Player、Resource Pack、发布包或远端产物。
