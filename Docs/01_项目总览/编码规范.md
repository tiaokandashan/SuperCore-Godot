# 编码规范

状态：当前有效  
最后更新：2026-08-10

## 当前已确认规则

- 项目自有目录、C# 文件、类型和节点使用 `PascalCase`；框架运行时目录保留原有专用拼写 `RunTime`。
- C# 文件名与主要类型名一致，例如 `SuperCore.cs`、`ModuleRunner.cs`；接口保留 `I` 前缀。
- 命名空间按职责使用 `PascalCase`，当前框架命名空间为 `SuperCore.RunTime`。
- private 字段使用 `m_` + `PascalCase`；参数和局部变量使用 `camelCase`；方法和属性使用 `PascalCase`。
- 启用 nullable reference types；空状态必须显式表达和校验。
- Godot 可挂载 C# 类型声明为 `partial`，Node 生命周期只存在于明确的 Host 类型中。
- 需要在 Inspector 创建的自定义 Resource 使用 `[GlobalClass] public sealed partial class ... : Resource`，文件名必须与类名完全一致。
- Resource 的可编辑数据可以继续使用 `[Export] private m_...` 字段和只读 getter；类型为 `Godot.Collections.Array<T>` 时，`T` 必须是 Variant 兼容类型。
- Module 是普通 C# 类，不继承 `GodotObject` 或 `Node`。
- 参与框架启动的 Module 使用 `[Module(priority)]` 声明优先级；特性存在即启用，移除特性即不参与收集，不另建 Module 注册 Resource。
- Module 自有配置类型和 `.tres` 放在对应 Module 目录；配置资源继续使用 `Cfg_<Name>.tres`，不承担 Module 注册职责。
- 帧时间使用 `double`，避免在 Godot `_Process(double delta)` 边界无意义降精度。
- 场景等项目资源使用 `<Type>_<Name>` 格式，当前主场景为 `Scn_GameMain.tscn`。
- Godot 固定文件和目录名保持引擎要求，例如 `project.godot`、`.godot`。

具体 Module、资源、Editor 和业务新增特殊规则时，必须以真实实现为依据继续补充，不能提前写入未采用的约定。
