# AI 文档规范

状态：当前有效  
适用范围：SuperCore Godot 当前文档和修改任务  
最后更新：2026-08-06  
AI阅读优先级：高

## 一、规范定位

本规范定义任务身份、索引、根迁移依赖、结构化日志和文档状态，并与 `AGENTS.md`、工作流程、文档维护和日志规范共同组成 AI 工作体系。

- 当前代码、资源、配置和工作区状态是最高事实源。
- 当前有效文档回答“现在是什么”；方案与日志回答“为什么这样改”。
- 待补充文件只预留路由，不代表功能已实现。
- 历史任务不能替代对实际文件、调用点和迁移源的重新读取。

## 二、增删改查

- `create`：新增持久化能力、文件、资源、配置或文档。
- `delete`：删除已有能力、文件、资源、配置或文档。
- `update`：修改、修复、重构、迁移、移动或重命名。
- `query`：只读查询、诊断、解释或审查，不产生持久化修改。

`create`、`delete`、`update` 在有效确认后创建任务；`query` 不创建任务。复杂方案在确认前只进入 `Docs/05_任务/待确认`，不占任务编号。

## 三、任务身份

任务编号格式：

```text
SCG-YYYYMMDD-NNN
```

- 日期为首次确认进入实施的日期，序号按当天已有最大值递增。
- 编号创建后不复用。
- `SCG-20260806-001` 固定为 SuperCore 框架完整迁移根任务，直到全框架最终验收成功才完成。

责任人解析顺序：根 `AGENTS.md` 的 `UserName:`、项目根 `git config --get user.name`、用户手动提供。读取结果只用于任务，不修改 Git 配置。

## 四、根任务与依赖

除根任务自身外，所有迁移任务 YAML 必须包含：

```yaml
root_task: SCG-20260806-001
```

`root_task` 表示任务属于完整迁移，不要求根任务先完成。真正阻塞执行的前置任务写入：

```yaml
relations:
  depends_on: [SCG-...]
```

- 根任务保持 `draft`，所有子任务完成也不能自动完成根任务。
- 根任务完成需要迁移清单闭合、所有子任务完成、完整构建与运行验证、编辑器验收、文档闭合和用户最终确认。
- 与迁移无关的项目任务可以不填写 `root_task`，但必须在关系审查中说明独立原因。

## 五、任务状态

- `draft`：已确认并登记，尚未最终完成。
- `paused`：暂时搁置，仍属于未完成任务。
- `completed`：实现、文档、审查和验证全部完成。
- `cancelled`：确认后取消。
- `superseded`：被后续任务替代。
- `reverted`：实现被后续任务撤销。

## 六、文档职责

| 信息 | 唯一位置 |
| --- | --- |
| 当前实现事实 | 当前源码、资源、配置和 `Docs/01-04` 当前文档 |
| 当前未完成任务 | `Docs/01_项目总览/任务索引.md` |
| 月份任务定位 | `Docs/05_任务/索引/YYYY-MM.md` |
| 复杂方案资料 | `Docs/05_任务` 对应状态目录 |
| 正式任务详情 | `Docs/06_日志/Log(X月Y周[-N]).md` |
| 失效旧资料 | `Docs/90_历史归档` |

总索引不复制全部历史，月索引不复制任务正文，正式任务详情只写在周日志。

## 七、结构化任务模板

```yaml
id: SCG-YYYYMMDD-NNN
status: draft
operation: update
created_by: "user-name"
executed_by: ["user-name"]
root_task: SCG-20260806-001
proposal: "Docs/05_任务/进行中/任务方案.md"
areas: [framework]
targets:
  files: []
  symbols: []
relation_status: linked
relations:
  continues: []
  depends_on: []
  supersedes: []
  reverts: []
  conflicts_with: []
started_at: 2026-08-06
completed_at:
```

正文顺序固定为：`目标 -> 结果 -> 决策 -> 约束 -> 文档 -> 后续 -> 审查 -> 验证`。

## 八、索引一致性

- 创建未完成任务时同步写总索引、月索引和周日志。
- 暂停任务继续留在总索引，方案移入 `搁置`。
- 完成后先更新当前文档和日志，再更新月索引并从总索引移除。
- 索引与日志不一致时以结构化日志为准修复索引。
- 创建、恢复和完成任务前必须检索根任务、直接依赖和冲突任务。
