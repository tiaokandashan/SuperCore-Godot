# 模块索引

状态：当前有效  
最后更新：2026-08-10

当前已经迁移 `IModule`、`Module<T>`、`ModuleRunner` 生命周期基础和 `[Module(priority)]` 运行时发现。以下具体类型仅建立了同步调用 `CompleteInit()` 的启动骨架，真实功能均未迁移：

- `ResModule`、`DebugModule`、`EventModule`、`HotUpdateModule`
- `TimerModule`、`UpdateModule`、`TableModule`、`LocalizationModule`
- `AudioModule`、`UIModule`、`EntityModule`、`ProcedureModule`

- 框架生命周期：[启动流程与 Module 生命周期](启动流程与Module生命周期.md)
- 各模块目录中的空配置 Resource 仅确定归属和资源类型，尚未接入骨架。
- Res、Update、Event、Timer、UI 等具体能力仍为待迁移状态；完成各自源审计和 Godot 验收后再登记功能实现。
